## Overview
This academic Tableau project analyzed FEMA disaster declaration data across the United States. The dashboard was created to visualize disaster activity by state, incident type, and time period.

## Project Objective

The goal of this project was to build an interactive dashboard that helps users explore FEMA disaster declaration trends using maps, tables, filters, and monthly trend visualizations.

## Tools Used
- Tableau
- FEMA disaster declaration data
- Data visualization
- Dashboard design
- Geographic mapping

## What I Did
- Built an interactive Tableau dashboard using 64,000+ FEMA disaster declaration records
- Created a state map to visualize disaster declarations by location
- Added an incident table to summarize disaster records and categories
- Built monthly disaster trend visuals to show changes over time
- Added filters by state and incident type to support interactive analysis
